## 🇺🇸 English

### 📝 About the Project
This project is the culmination of the **Alura Data Immersion with Python**. It represents a journey from raw data exploration to the deployment of a functional interactive dashboard. The app allows users to filter global salary information by year, experience level, employment type, and company size.

### 🚀 The Learning Journey
* **Lesson 1 (Exploration):** Data loading with **Pandas**, metadata inspection (`.info`, `.describe`), and initial data cleaning/renaming.
* **Lesson 2 (Data Cleaning):** Handling missing values (`NaN`) and type casting (`astype`) to ensure data integrity for analysis.
* **Lesson 3 (Visual Analysis):** Creating statistical visualizations like **Boxplots** for outlier detection and interactive **Donut Charts** with **Plotly**.
* **Lesson 4 (Deployment):** Migrating from Google Colab to **VSCode**, building the UI with **Streamlit**, and deploying the live application via **Streamlit Cloud**.

## 🇧🇷 Português

### 📝 Sobre o Projeto
Este projeto é a culminação da **Imersão de Dados com Python da Alura**. Ele representa uma jornada que vai da exploração de dados brutos até a publicação de um dashboard interativo funcional. O dashboard permite filtrar informações salariais globais por ano, nível de experiência, tipo de trabalho e tamanho da empresa.

### 🚀 Jornada de Aprendizado
* **Aula 1 (Exploração):** Carregamento de dados com **Pandas**, inspeção de metadados (`.info`, `.describe`) e limpeza inicial/renomeação de colunas.
* **Aula 2 (Tratamento):** Manipulação de valores ausentes (`NaN`) e conversão de tipos de dados (`astype`) para garantir a integridade da análise.
* **Aula 3 (Análise Visual):** Criação de visualizações estatísticas como **Boxplots** para detecção de outliers e **Gráficos de Rosca** interativos com **Plotly**.
* **Aula 4 (Publicação):** Migração do Google Colab para o **VSCode**, construção da interface com **Streamlit** e deploy da aplicação via **Streamlit Cloud**.
